🗂️ Where Windows Logs Live

📁 File Location

C:\Windows\System32\winevt\Logs\

Format: .evtx

Read with: Event Viewer, wevtutil, Get-WinEvent

📋 Core Channels

System: OS events, drivers, services

Application: App crashes, installers

Security: Logons, privilege use, audit

Setup: OS installs/upgrades

🛡️ Security Channel

4625: Failed logon

4624: Successful logon

4672: Special privileges

1102: Log cleared

🔢 Logon Types — What "Type 3" Actually Means

Every successful logon (Event 4624) records a number called LogonType. This number tells you HOW the user authenticated. Knowing this is critical — Type 10 from an unfamiliar IP is a red flag. Hover each type to see what it means.

Type 2

Interactive — user is physically at the keyboard.

Common for: normal workstation logins

Suspicious if: seen on a server where no one should be at the console

Type 3

Network — user accessed a shared resource remotely.

Common for: file shares, mapped drives, web app auth

Suspicious if: many Type 3 logons across many hosts = lateral movement

Type 4

Batch — scheduled task executed.

Common for: cron-equivalent scheduled jobs

Suspicious if: unexpected scheduled tasks show up (persistence)

Type 5

Service — a service process logged in.

Common for: SQL Server, IIS, backup agents

Suspicious if: a normal user account used as a service

Type 7

Unlock — user unlocked their workstation.

Common for: returning to a locked machine

Suspicious if: off-hours unlock on a shared machine

Type 8

NetworkCleartext — plaintext credentials over the wire.

Common for: IIS basic auth, legacy apps

Suspicious if: anything else — investigate the source

Type 9

NewCredentials — runas /netonly.

Common for: admins using alternate creds for one app

Suspicious if: non-admin account doing it

Type 10

RemoteInteractive — RDP session.

Common for: admins connecting to servers

Suspicious if: unusual source IP or unexpected target host

Type 11

CachedInteractive — offline logon with cached creds.

Common for: laptops off-VPN

Suspicious if: seen on servers (servers shouldn't cache)
