Anatomy of a Log Line

Every log line has the same four parts. Learn them once, read every log forever.

Jan 15 14:23:45  server  sshd[1234]:  Failed password for invalid user admin from 203.0.113.5
─────────────    ────    ──────────    ────────────────────────────────────────────────────
1. Timestamp     2.Host  3. Source      4. Event message

1. Timestamp

When did it happen? Check UTC vs local.

2. Host

Which machine logged it? Essential in central logging.

3. Source

Which process? Includes PID: sshd[1234].

4. Message

The actual event — where the signal lives.

🗂️ Where Logs Live

🐧 Linux

All logs live under /var/log/

System: syslog, messages, kern.log

Auth: auth.log (Debian), secure (RHEL)

Web: apache2/, nginx/

Binary: wtmp, btmp, lastlog

🪟 Windows

Event logs live in C:\Windows\System32\winevt\Logs\

System: System.evtx

Application: Application.evtx

Security: Security.evtx

Sysmon: Microsoft-Windows-Sysmon/Operational.evtx
